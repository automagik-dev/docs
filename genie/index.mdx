**Code is a commodity. Harnesses get replaced. Context stays.**

Genie is a set of skills for coding agents, plus a small CLI. It takes an idea through a reviewed design, a plan, the code and an independent review to a pull request. Designs and plans stay in your repository as markdown, with the reviews that approved them, so the next agent you use reads the same context.

```bash
curl -fsSL https://raw.githubusercontent.com/automagik-dev/genie/main/install.sh | bash
```

## How a change moves

You drive Genie through skills. Claude Code runs a skill as `/wish`, Codex as `$wish`, and other agents by its name or by a plain request such as "deliver this".

**One decided task** goes to [wish](/genie/skills/wish). It checks that the task fits a single wish, makes the change in its own git worktree, runs your repository's checks, has a different agent review the commit and opens a pull request. You merge it.

**Work bigger than one task** takes the whole loop:

| Step | Skill | What you get |
|------|-------|--------------|
| Design | [brainstorm](/genie/skills/brainstorm) | A `DESIGN.md`, approved by a design review before any plan is written |
| Plan | [wish](/genie/skills/wish) | A `WISH.md` with execution groups, approved by a plan review before anything is built |
| Build | [work](/genie/skills/work) | Each group done by its own scoped worker, in dependency order |
| Check | [review](/genie/skills/review) | SHIP, FIX-FIRST or BLOCKED against the plan's criteria |
| Repair | [fix](/genie/skills/fix) | The blocking gaps closed within a bounded budget, then checked by a fresh reviewer |

Each review in that table is done by an agent that did not do the work. [council](/genie/skills/council) sits outside the loop: bring it a hard decision and it returns independent views and a synthesis, without changing anything.

## Where the context lives

- Designs, plans and review verdicts are markdown files under `.genie/brainstorms/<slug>/` and `.genie/wishes/<slug>/`. They go through git with your code.
- Task state lives in one SQLite file per repository, `.genie/genie.db`, which every worktree of that repository shares. `genie board` shows it as a kanban.
- No Genie process stays running: every `genie` command does its work and exits.

## Which agents

| Agent | Skills | Saved workflows |
|-------|--------|-----------------|
| Claude Code | `~/.claude/skills`, run as `/wish` | Yes, from `~/.claude/workflows` |
| Codex | The shared `~/.agents/skills`, run as `$wish` | No. The skills run the same stages by hand |
| Other agents skills.sh supports | Their own skills home, such as `~/.config/goose/skills`, or the shared `~/.agents/skills`, run by name | No. The skills run the same stages by hand |
