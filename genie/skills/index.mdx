A skill is a markdown procedure your agent loads by name. Genie v6.261002.2 ships 18. `genie install` and `genie update` deliver them through skills.sh into every agent skills home Genie detects: `~/.claude/skills` for Claude Code, and the shared `~/.agents/skills` for Codex and the other agents that read it.

Claude Code runs a skill as `/wish`, Codex as `$wish`, and any other agent by its name or by a plain request. Each card shows both forms.

## The loop

The skills that take a change from an idea to a pull request, plus council for the decisions along the way. Each has its own page.

<CardGroup cols={2}>
  <Card title="brainstorm" img="/genie/images/skills/brainstorm.svg" href="/genie/skills/brainstorm">
    Settles an open idea with you, one round at a time, into a `DESIGN.md` that an independent reviewer approves.
  </Card>
  <Card title="wish" img="/genie/images/skills/wish.svg" href="/genie/skills/wish">
    Takes one decided task to a merge-ready pull request, or refuses it and names the route it needs.
  </Card>
  <Card title="work" img="/genie/images/skills/work.svg" href="/genie/skills/work">
    Runs an approved `WISH.md` in dependency order, one scoped worker per group, and ends at an implementation review.
  </Card>
  <Card title="review" img="/genie/images/skills/review.svg" href="/genie/skills/review">
    Reads a design, plan, diff or pull request without changing it and returns SHIP, FIX-FIRST or BLOCKED with evidence.
  </Card>
  <Card title="council" img="/genie/images/skills/council.svg" href="/genie/skills/council">
    Puts a consequential decision through independent lenses, dissent included, and returns a synthesis. It edits nothing.
  </Card>
  <Card title="fix" img="/genie/images/skills/fix.svg" href="/genie/skills/fix">
    Repairs the blocking gaps of a FIX-FIRST review within a bounded budget, each repair checked by a different reviewer.
  </Card>
</CardGroup>

## Workflows behind the skills

These skills start a saved workflow. In Claude Code the skill runs the workflow from `~/.claude/workflows`, or from your repository's own `.claude/workflows/` when it carries one. In Codex and other agents without saved workflows, the same skill runs the stages by hand.

| Skill | Saved workflow |
|-------|----------------|
| `brainstorm` | `brainstorm` |
| `council` | `council` |
| `docs` | `docs-audit` |
| `research` | `research-sweep` |
| `skill-audit` | `skill-audit-sweep`, and `skill-intake` for candidate skills from outside the catalog |
| `wish` | `wish` |
| `workfly` | `workfly` |

These workflows have no skill in front of them: `evidence-gate`, `observability-review`, `pm-ledger-verify` and `test-simplify`. [Workflows](/genie/workflows) describes each of the 12.
