<Note>
  Genie isn't one big feature — it's a set of small, composable capabilities that turn "AI can code" into "AI can ship." Each one solves a specific coordination problem. Together, they become a coherent orchestration layer.
</Note>

<CardGroup cols={2}>
  <Card title="Wishes — Structured Intent" icon="scroll" href="/genie/concepts/wishes">
    Define what to build once — scope, acceptance criteria, execution groups — and never re-explain it to another agent.
  </Card>
  <Card title="Pipeline — Brainstorm to Ship" icon="arrows-spin" href="/genie/skills/work">
    Brainstorm, design review, wish, plan review, work, implementation review. Each stage has a skill and a gate, and a verdict alone never advances state.
  </Card>
  <Card title="One File of State" icon="database" href="/genie/config/files">
    Tasks, lanes, and dependency edges in a single per-repo SQLite file. No daemon, no server, no port — a command opens it, runs one transaction, and exits.
  </Card>
  <Card title="Documents in Git" icon="file-lines" href="/genie/concepts/wishes">
    Wishes, designs, and the index are plain markdown under `.genie/`. You diff, review, and version a plan like any other code.
  </Card>
  <Card title="Boards Derived by Query" icon="columns-3" href="/genie/cli/boards">
    `genie board` has no stored view state to go stale, and `genie idea` drops a thought straight into the Idea lane. The roadmap snapshot in git is the canonical board.
  </Card>
  <Card title="Orca Lifecycle Authority" icon="plug" href="/genie/cli/infrastructure">
    Hand the lifecycle to Orca with one explicit, reversible command. Orca mode refuses what it forbids at exit 2 instead of keeping a shadow copy — and there is no fallback database in either direction.
  </Card>
  <Card title="Saved Workflows" icon="wand-magic-sparkles" href="/genie/skills/loop-overview">
    A catalog of scripts for procedures worth running the same way twice — `council`, `docs-audit`, `skill-intake` — installed to `~/.claude/workflows` alongside the skills.
  </Card>
  <Card title="Microagents — genie mikro" icon="robot" href="/genie/architecture/overview">
    Narrow agents with an answer schema, returning validated JSON whose every citation is verified. `init`, `fixtures`, `bench` and `coach` seed, measure and refine a repository's own agents.
  </Card>
  <Card title="Wish Linting" icon="circle-check" href="/genie/skills/wish">
    `genie wish lint` checks any repository's `.genie/wishes` for structure, writes nothing, and exits 0 or 1 — so a malformed plan fails before an agent acts on it.
  </Card>
  <Card title="Skills Channel" icon="share-nodes" href="/genie/installation">
    One install path to every agent skills.sh supports. Retirement runs before the install pass, every removal is backup-first, and the record is what `doctor` reads and `uninstall` proves against.
  </Card>
  <Card title="Verified Delivery" icon="shield-check" href="/genie/security/verifying-installs">
    Every release verifies offline, with no GitHub credential — signed delivery evidence checked against an embedded trust root and bound to the tarball's hash before anything is extracted.
  </Card>
  <Card title="Provider Agnosticism — BYOA" icon="plug" href="/genie/concepts/byoa">
    Claude, Codex, Goose, or your custom agent. The skills are runtime-neutral by construction, so Genie installs no agent profiles and no hooks.
  </Card>
</CardGroup>
